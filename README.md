# Harum Laundry Kota Tarakan

Ini adalah project pertama yang dibangun oleh perusahaan SiuWeb dengan client CV Harum Laundry. Berlokasi di Kota Tarakan, Harum Laundry telah
memiliki 3 cabang yang tersebar merata di seluruh wilayah Kota Tarakan.

<br>

Adapun cabang terdiri dari: 
- Cabang Utama Harum Laundry (Jl. Mulawarman Perumnas No. B1, Karang Anyar, Kec. Tarakan Barat, Kota Tarakan, Kalimantan Utara 77111)
- Cabang 2 Harum Laundry (Jl. Aki Balak, Juata Kerikil, Tarakan Utara, Kalimantan Utara)
- Cabang 3 Harum Laundry (Jl. P. Nias, Kelurahan Skip, Tarakan Tengah, Kalimantan Utara)

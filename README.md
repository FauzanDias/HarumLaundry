# Aplikasi Harum Laundry

## Latar Belakang

Aplikasi Harum Laundry merupakan aplikasi pengelolaan data dan juga informasi untuk layanan laundry. Aplikasi ini dikembangkan untuk membantu pemilik usaha dalam mengelola pesanan, pengguna, dan lainnya. Selain itu, terdapat pencatatan dan pengelolaan laporan untuk transaksi yang dilakukan.

## Rumusan Masalah

1. Bagaimanacara mempermudah proses pencatatan pada transaksi laundry?
2. Bagaimana cara mengurangi human error dalam pencatatan transaksi?
3. Bagaimana cara memanfaatkan teknologi untuk proses pencatatan transaksi pada bidang usaha laundry?
